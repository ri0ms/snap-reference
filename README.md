# Reference

친구끼리 찾은 **스냅사진 레퍼런스**를 6개 컨셉으로 나눠 모으고, 서로 실시간으로 확인하는 웹 보드.

각자 찾은 사진을 카카오톡·개인 폴더·핀터레스트에 제각각 모으다 보니 상대방이 뭘 모았는지 그때그때 볼 수 없고, 의견은 이미지와 따로 놉니다. Reference는 **모으는 곳 = 보는 곳 = 이야기하는 곳**을 하나로 합칩니다.

## 구조

```
보드
├── 1. 개인          ← 카테고리 6개, 고정 (추가·삭제 없음)
├── 2. 커플
├── 3. 친구·우정
├── 4. 일상스냅
├── 5. 셀프웨딩
└── 6. 웨딩스튜디오
        └── 야외 / 실내 / 필름톤 …   ← 폴더, 사용자가 생성 (1단계까지만)
```

- **카테고리**는 6개 고정입니다. 사진 1장은 카테고리 1개에만 속합니다.
- **폴더**는 카테고리 안에서 사용자가 만듭니다. 사진 1장은 폴더 0~1개에 속합니다.
- 폴더 안에 폴더는 만들 수 없습니다.

## 화면

| 화면 | 역할 |
|---|---|
| 보드 홈 | 대형 타이틀 + 6개 카테고리 카드 1행 |
| 카테고리 상세 | 저스티파이드 그리드 + 폴더 칩 + 업로드 (보기와 올리기가 같은 화면) |
| 이미지 상세 | 원본 크게 보기 + 댓글 + 다운로드 (오버레이) |

깊이는 3단계까지만 둡니다.

---

## 핵심 원칙

1. **색은 사진이 쓴다** — 넓은 면은 무채색 고정. 강조색(틸 그린 `#0D7370`)은 제목과 누를 수 있는 것에만, 글자와 선에만
2. **사진 비율을 자르지 않는다** — 스냅 레퍼런스는 프레이밍 자체가 참고 대상
3. **다크 모드 없음** — 배경 밝기가 바뀌면 같은 사진의 톤이 다르게 보임

## 지금 상태

**시험판 (v0.1)** — 화면과 조작은 모두 동작하지만, 저장이 각자 브라우저 안에서만 이뤄집니다.

### 되는 것

- 6개 카테고리 보드 홈 · 카테고리별 장수와 대표 이미지(최신 1장) 자동 표시
- 업로드 — 드래그 앤 드롭 / 버튼 / `Ctrl+V` 붙여넣기 (한 번에 10장, 장당 10MB)
- 저스티파이드 그리드 — 행마다 높이를 맞추고 폭은 원본 비율대로, 사진을 자르지 않음
- 폴더 생성 / 이름 변경 / 삭제, 폴더별 필터 (폴더를 지워도 사진은 `전체`에 남음)
- 여러 장 선택 → 폴더로 이동 / 다운로드 / 삭제 (삭제는 본인이 올린 것만)
- 원본 크게 보기 + 댓글 + 원본 다운로드, 키보드 `←` `→` `Esc`
- 모바일 2열 그리드, 카테고리 딥링크 (`#/self-wedding`)

### 아직 안 되는 것

| 항목 | 이유 |
|---|---|
| **친구와 공유** | 사진이 브라우저 저장소(IndexedDB)에만 저장됩니다. 서버 저장소를 붙여야 합니다 |
| **링크 이미지 추출** | 다른 사이트의 OG 태그를 읽으려면 서버(프록시)가 필요합니다 |

기술 스택은 없습니다. 바닐라 HTML/CSS/JS 단일 파일이라 빌드도 설치도 필요 없습니다.
